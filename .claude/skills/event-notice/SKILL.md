# 行事の SNS 告知文

引数 `$ARGUMENTS` が日数。空なら 14。

## 手順

1. 対象の行事を出す。日付は自分で数えず、必ずこの出力を使う

   ```sh
   node --import ./scripts/diff-pythaidate/resolve-ts.mjs .claude/skills/event-notice/upcoming.ts <日数>
   ```

   今日〜今日+日数（両端を含む）に 1 日でもかかる行事が出る。期間の行事（トートカティン）は、開始日が今日より前でも期間中なら出る。日付は `date +%a` で曜日を確かめる

2. 行事ごとに 1 投稿書く。同じ行事が複数回あれば（ワンプラ）、1 投稿に日付を並べる
   - 日本語で、リンクを含めて 140 字以内
   - 行事名は `カタカナ（日本語訳）`。例: ワンプラ（布薩日）。タイ文字は書かない（ADR-0012）
   - 本文は `src/content/events/<id>.md` の frontmatter の `practice` と「行うこと」だけから要約する。「由来」（`origin`）は使わない
   - 断定できない由来は書かない。「行うこと」の中でも、注釈書由来や「このカレンダーでは扱わない」とされた事柄は書かない
   - 末尾に詳細ページ `/events/<id>` へのリンク。astro.config に `site` が無いうちは相対パスのまま
3. 文字数を数え、140 字を超えた投稿は削る

   ````sh
   awk '/^```$/{f=!f;next} f' docs/notices/<今日の日付>.md | while IFS= read -r l; do printf '%s' "$l" | wc -m; done
   ````

4. `docs/notices/<今日の日付>.md` に保存する。形は下のとおり。対象が 0 件ならファイルは作らず、そう伝えて終わる
5. コミット・投稿はしない。保存先と、各投稿の文字数、リンクが相対パスであることをユーザーに伝える

## ファイルの形

````md
# SNS 告知文の下書き（<今日> 作成）

対象: <今日>〜<終わり>（今日から <日数> 日以内）に当たる行事。日付は src/core の `occurrences` と src/data/events.ts から計算した。
本文は src/content/events/<id>.md の practice と「行うこと」から要約した。

| 行事               | 日付                   | 太陰暦                                     |
| ------------------ | ---------------------- | ------------------------------------------ |
| ワンプラ（布薩日） | 2026-10-26, 2026-11-03 | 太陰暦 11 月の満月 / 太陰暦 11 月後半 8 日 |

## ワンプラ（布薩日）

```
10/26（月）と11/3（火）はワンプラ（布薩日）。……。 /events/wan-phra
```
````
