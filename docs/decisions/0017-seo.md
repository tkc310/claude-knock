# 0017 canonical・JSON-LD・sitemap.xml で検索エンジンに伝え、ヘッダーのロゴを logo.svg にする

- 日付: 2026-10-22
- 状態: 採用

## 背景

サイトを `https://koyomi.tkc310.com` で公開した（ADR-0016）。利用者から SEO の対策（canonical、sitemap.xml、JSON-LD）と、OGP の画像に `og.png` を使うこと、ヘッダーのロゴに `logo.svg`（ロゴ A 案）を使うことを求められた。

## 決定

- どのページにも `<link rel="canonical">` と `og:url` を、`astro.config.mjs` の `site` で絶対 URL にして出す。`og:image` も `https://koyomi.tkc310.com/og.png` にする（`src/layouts/Base.astro`）
- JSON-LD は 1 ページに 1 つの `@graph` にまとめる。どのページにも `WebSite`（名前・URL・言語・説明）を、トップ以外には `BreadcrumbList`（トップ → そのページ）を出す。`<` は `<` にして `</script>` で途切れないようにする
- `sitemap.xml` は依存（`@astrojs/sitemap`）を足さず、`src/pages/sitemap.xml.ts` の静的エンドポイントで作る。載せるのはトップ・タンブン・行事の詳細ページ
- `robots.txt` も `src/pages/robots.txt.ts` で作り、`Sitemap:` を絶対 URL で書く。`public/robots.txt` は消す
- `sitemap.xml` と `robots.txt` は Service Worker の保存の対象から外す
- ヘッダーのロゴは、法輪の SVG とサイト名の文字の組み合わせをやめ、`public/logo.svg` の `<img>`（`alt` はサイト名）にする

## 理由

- canonical と sitemap は、同じページが別の URL（workers.dev など）で見つかったときにも、正しい URL を検索エンジンに伝える
- 行事は全国で行われる宗教行事で、場所や主催者を持つ schema.org の `Event` の条件に合わない。誤った構造化データを出すより、サイトとページの階層だけを確かに伝える
- ページは 11 しかなく、一覧も `src/data/events.ts` にあるので、sitemap の依存を足すほどではない
- ロゴを画像にすると、ヘッダーと OGP・README のロゴが同じものになる。文字はアウトライン化してあるので、書体が無くても崩れない

## 影響・トレードオフ

- `site` を変えると、canonical・OGP・sitemap・robots.txt の URL がまとめて変わる
- 新しいページを足したら、`src/pages/sitemap.xml.ts` の一覧にも足す（`tests/pages.test.ts` が全ページを確かめる）
- ヘッダーのロゴの文字は画像の一部になるので、文字の大きさの変更（ブラウザの文字拡大）には追従しない。`alt` で読み上げは保つ
