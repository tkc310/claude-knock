# 0005 対象を原始仏教にとって重要な行事に限る

- 日付: 2026-10-20
- 状態: 採用

## 背景

最初の行事一覧には、ロイクラトンとソンクラーンが入っていました。追加候補を調べるうちに、仏教行事として扱うかどうかの基準が無いことが分かりました。

## 決定

対象は、パーリ三蔵（経・律）かブッダの生涯に根拠がある行事に限ります。民間の習俗、地方の祭り、バラモン教に由来する儀礼は扱いません。
この基準で、ロイクラトン（水の女神に感謝する民間の祭り）とソンクラーン（バラモン教の暦に由来する太陽暦の正月）を外しました。
候補ごとの判断は [`docs/events/candidates.md`](../events/candidates.md) に残します。

## 理由

- 行事を足すたびに、同じ基準で判断できる
- 太陽暦の行事が無くなり、すべての行事をタイ太陰暦の規則で表せる

## 影響・トレードオフ

- 旅行者に人気の行事（ロイクラトン、ソンクラーン）がカレンダーから消える
- 太陽暦の行事の型（`SolarEvent`）を消した。太陽暦の行事を足すときは、この ADR を廃止して新しい ADR を書く
