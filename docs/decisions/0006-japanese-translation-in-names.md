# 0006 行事名に日本語訳を加える

- 日付: 2026-10-20
- 状態: 一部置き換え（タイ語の表示は ADR-0012 で外した）

## 背景

行事名は「タイ語 / ローマ字 / カタカナ」の 3 表記でした。カタカナは音写なので、「カオパンサー」から雨安居の始まりだと読み取れません。

## 決定

行事名を「タイ語 / ローマ字 / カタカナ / 日本語訳」の 4 表記にします（例: วันเข้าพรรษา / Khao Phansa / カオパンサー / 入安居）。
日本語訳は意味をとった訳で、日本の仏教で定着した語があればそれを使います（布薩日・入安居・出安居など）。

| 行事                     | 日本語訳       |
| ------------------------ | -------------- |
| ワンプラ                 | 布薩日         |
| マーカ・ブーチャー       | 万仏節         |
| ウィサーカ・ブーチャー   | 仏誕節         |
| アーサーラハ・ブーチャー | 三宝節         |
| カオパンサー             | 入安居         |
| オークパンサー           | 出安居         |
| トートカティン           | カティナ衣奉献 |

## 理由

- 日本語の読み手が、行事の意味を名前から分かる
- 布薩・安居・カティナ衣は律に出てくる語で、原始仏教の行事に限るという基準（ADR-0005）とつながる

## 影響・トレードオフ

- 表示名が長くなる。Web のカード見出しと ICS の件名が 4 表記になる
- ウィサーカ・ブーチャーは誕生・成道・涅槃の 3 つを記念する日だが、日本語で定着した「仏誕節」を使う。3 つの意味は行事の解説（`docs/events/`）で補う
