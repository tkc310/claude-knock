# 0012 サイトと配信からタイ文字を外し、説明を短くする

- 日付: 2026-10-21
- 状態: 採用

## 背景

行事名は「タイ語 / ローマ字 / カタカナ / 日本語訳」の 4 表記（ADR-0006）で、本文や太陰暦の日付（`ขึ้น 15 ค่ำ เดือน 3` など）にもタイ文字が多く出ていました。日本語の読み手には読めず、画面が込み入っていました。本文も長く、由来と行うことが一目で分かりませんでした。

## 決定

- サイト（Web）・ICS・SNS 告知文にはタイ文字を出さない。`src/data/events.ts` の `name` から `th` を外す
- 行事名は「カタカナ（日本語訳）/ ローマ字」と書く（例: ワンプラ（布薩日）/ Wan Phra）。ICS の件名は「カタカナ（日本語訳）」
- 太陰暦の日付は日本語で書く（例: 太陰暦 3 月の満月、太陰暦 8 月（2 回目）後半 1 日）。前半は白分、後半は黒分
- 行事の本文の frontmatter は `origin`（由来）と `practice`（行うこと）の 2 つを 1 行ずつ書き、一覧のカードにも出す
- 調査メモ（`docs/events/`）と `src/core` のコメントは、出典との照合に要るのでタイ語のまま残す

## 理由

- 日本語の読み手が、行事の意味と日付をすぐ読み取れる
- 出典との照合はタイ語の表記が要るが、それは調査メモの役目で、サイトの読み手には要らない

## 影響・トレードオフ

- ADR-0006 の 4 表記のうち、タイ語を表示から外す（日本語訳を加える判断はそのまま）
- タイ語の行事名を手がかりに現地の情報を探す読み手には、手がかりが減る。出典のリンクは残す
- `tests/content.test.ts`・`tests/pages.test.ts`・`tests/core/ics.test.ts`・`tests/data.test.ts` がタイ文字の混入を検査する
