# docs/events

行事ごとの解説を置く。1 行事 1 ファイル、ファイル名は `src/data/events.ts` の `id`（例: `wan-phra.md`）。

各ファイルの見出しは「タイ語 / ローマ字 / カタカナ / 日本語訳」を併記する（`src/data/events.ts` の `name` と同じ）。

```md
# วันพระ / Wan Phra / ワンプラ / 布薩日
```

日付の決め方（太陰暦の規則など）と、出典 URL を必ず書く。

## 行事どうしの日付の関係

各行事のファイルに書いた規則が互いに矛盾しないかを、2024〜2027 年の日付で確かめた結果（2026-10-21）。
太陰月は約 29.53 日なので、1 か月 ≈ 29〜30 日、2 か月 ≈ 59 日、3 か月 ≈ 88〜89 日になる。2026 年（仏暦 2569）は閏月（เดือน 8 が 2 回）の年。

### 規則で退けた日付と、ファイルの直すところ

- オークパンサー 2026 年を 10-06 とする外国の観光サイトは、カオパンサー（07-30）の 3 か月後（10-26）と合わない。誤り（`ok-phansa.md`）
- カオパンサー 2026 年を 07-31 とする検索結果の要約は、アーサーラハ・ブーチャー（07-29、告示）の翌日と合わない。誤り（`khao-phansa.md`）
- マーカ・ブーチャー 2026 年を `เดือน 3`、ウィサーカ・ブーチャー 2026 年を `เดือน 6` とする報道は、閏月の年に 1 か月ずれる規則と合わない（`makha-bucha.md`・`visakha-bucha.md`）。日付は合っていて、月の呼び方だけが違う
- トートカティン 2025 年の終了日は、オークパンサー（10-07）の 1 か月後で 11-05 になるはず。開けなかった広報ラジオのページの 11-05 と合う。出典を開けたら埋める（`thot-kathin.md`）
- `thot-kathin.md` は「閏月の年にどうずれるか未確認」とするが、閏月（`เดือน 8 หลัง`）は `เดือน 11`・`เดือน 12` より前に入るので、太陰暦の上ではずれない。2026 年の日付もオークパンサーの翌日から始まっている
- `ok-phansa.md` の「閏月の年は約 1 か月遅れる」は太陽暦で見たときの話。太陰暦の規則（`ขึ้น 15 ค่ำ เดือน 11`）は閏月の年も変わらない
- `makha-bucha.md` の「`ขึ้น 15 ค่ำ เดือน 4`（`เดือน 3 หลัง` とも）」の「`เดือน 3 หลัง`」は、ほかの行事のファイルにも出典にも出てこない。タイ暦で 2 回ある月は `เดือน 8` だけなので、この呼び方は出典を確かめるまで使わない

### まだ確かめていないこと

- 閏月の年にマーカ・ウィサーカが 1 か月ずれる規則そのものを、仏教庁などの公式機関の文書で確かめていない（報道と、上の日数の関係で裏づけているだけ）
- カオパンサー・オークパンサー・トートカティンの 2025 年以降の日付は、公式機関の出典が無い（仏教庁・宗教局のサイトは 403 で開けなかった）
