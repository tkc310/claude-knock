# 追加する行事の検討（2026-10-20）

タイの仏教行事のうち、まだ扱っていないものを調べた結果です。
基準は「原始仏教にとって重要か」です。パーリ三蔵（経・律）に根拠があるか、ブッダの生涯の出来事に結びつくものを残し、民間の習俗・地方の祭り・バラモン教に由来する儀礼は外しました。

## 追加する

| 行事                                               | 日付の規則                                                            | 根拠                                                                                                                                                               |
| -------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| วันอัฏฐมีบูชา / Atthami Bucha / アッタミー・ブーチャー | แรม 8 ค่ำ เดือน 6。閏月の年は เดือน 7（ウィサーカ・ブーチャーの 8 日後） | ブッダの荼毘の日。荼毘は大般涅槃経（長部 16 経）に記される。現在は休日ではない。規則は https://www.thaipbs.or.th/news/content/328519（仏教庁を典拠として引く報道） |

## 例外として追加する（民間行事）

原始仏教の基準には合わないが、タイで仏教と結びついて国民的に行われるため、「民間行事」の印を付けて扱う（ADR-0007）。

| 行事                                              | 日付の規則                                               | 扱い                                                                                                                                         |
| ------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| ลอยกระทง / Loi Krathong / ロイクラトン / 灯籠流し | ขึ้น 15 ค่ำ เดือน 12（トートカティンの期間の最終日と同じ日） | 2026-10-20 に一度外し、2026-10-21 に例外として戻した。水の女神への感謝という民間の祭りだが、仏足跡の供養と結びつける説明もある               |
| สงกรานต์ / Songkran / ソンクラーン / タイ正月      | 太陽暦の 4/13〜15 に固定                                 | 2026-10-20 に一度外し、2026-10-21 に例外として戻した。バラモン教の暦に由来する正月だが、寺での積徳行（ทำบุญ）や仏像の水かけ（สรงน้ำพระ）を伴う |

例外はこの 2 つに限る。ほかの民間の行事を足すときは、新しい ADR を書く。

## 見送る

| 候補                                   | 理由                                                                                                                                                         |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ตักบาตรเทโว（タックバート・テーウォー） | オークパンサーの翌日（แรม 1 ค่ำ เดือน 11）。ブッダが忉利天から降りた日とされるが、その話は三蔵ではなく注釈書に由来する。オークパンサー（自恣）の注記にとどめる |
| วันโกน（ワンコーン）                    | ワンプラの前日で、行事ではない。王立学士院辞典に定義が 2 通りある（14 ค่ำ だけか、7 ค่ำ と 14 ค่ำ か）                                                          |
| วันธรรมสวนะ                             | ワンプラの別名                                                                                                                                               |
| สารทไทย（サートタイ）                  | 10 月末日（แรม 15 ค่ำ เดือน 10）の収穫と先祖供養の祭り。民間の習俗                                                                                             |
| ชักพระ（チャックプラ）                  | 南部の祭り。タックバート・テーウォーと同じ日（王立学士院辞典）                                                                                               |
| ยี่เป็ง（イーペン）                       | 北部（ランナー）の祭り。ロイクラトンと同じ日                                                                                                                 |
| ทอดผ้าป่า（トートパーパー）              | 決まった日が無い                                                                                                                                             |
| บุญบั้งไฟ、แห่เทียนพรรษา、王室カティン      | 日程を県や王宮庁が毎年決めるため、太陰暦から計算できない                                                                                                     |
| 王耕祭、สารทจีน                         | バラモン教の王室儀礼、中国暦の行事                                                                                                                           |
